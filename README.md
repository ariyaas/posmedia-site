# POS Media Global Website

This is the official website developed for POS Media Global using React and Tailwind CSS.

## 🚀 Tech Stack

* React (Vite)
* Tailwind CSS
* React Router

## 📦 Installation

```bash
npm install
npm run dev
```

## 🏗 Build for Production

```bash
npm run build
```

## 🌐 Deployment

This project is ready for deployment on platforms like:

* Vercel
* Netlify
* Any Node.js hosting

## ⚙️ Important

Ensure SPA routing support is enabled:

Example (Vercel):

```json
{
  "routes": [
    { "src": "/(.*)", "dest": "/index.html" }
  ]
}
```
